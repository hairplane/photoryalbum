# 프로젝트 브리핑: [Zero-Server 프라이빗 아카이빙 캘린더] 개발 기획서

새로운 대화창에서 개발을 본격적으로 시작하기 위해 이전 대화에서 검증과 설계를 마친 핵심 내용을 전달합니다. 이 프로젝트의 핵심 철학, 기술 아키텍처, 세부 기능, 비즈니스 전략을 완전히 숙지한 상태에서 개발 파트너로서 협업을 이어가 주세요.

---

## 1. 프로젝트 비전 및 핵심 가치 (Core Value Proposition)
* **목표:** 서버 비용 $0, 무보수 유지보수, 개인 데이터 주권을 완벽히 보장하는 영구적 폐쇄형 추억 아카이브 웹 앱 구축.
* **타깃 유저:** 아이 성장 일기(20년치 기록), 반려동물 생애주기 케어, 가족/소규모 동호회의 고유 역사 보존.
* **차별점:** 
  * 수십 년 치의 기록을 브라우저 메모리상에서 0.01초 만에 즉시 필터링·검색하는 '초고속 타임머신'.
  * 상용 SNS/클라우드의 휘발성·파편화를 극복하고 정제된 역사만 영구 보존.
  * 일반 실시간 채팅을 배제하고 '디지털 방명록(댓글)'과 '카톡 카드 공유 브릿지'만 제공하여 조용하고 품격 있는 가족 박물관 유지.
* **출구 전략(Exit):** 개인 자격으로 개발·운영하여 수십만 MAU를 달성하더라도 서버비 $0인 지표를 증명한 뒤, 포토북 인쇄 커머스 기업, 폐쇄형 커뮤니티, 또는 펫 테크 기업에 자산 양수도(M&A) 매각 추진.

---

## 2. 인프라 및 통신 아키텍처 (Zero-Server Architecture)
* **프론트엔드 호스팅 (GitHub Pages):**
  * 단일 HTML/CSS/JS 파일(`calendar.html`) 기반 정적 배포.
  * 사용자가 접속 시 브라우저로 화면 UI(전단지)를 복사해 오면 GitHub과의 통신은 즉시 종료.
  * GitHub Fastly CDN 및 304 Not Modified(약 10분 캐시) 구조로 수만 명 동시 접속 시에도 개발자 부하 0.
* **배포 형태 (PWA - Progressive Web App):**
  * 앱스토어/플레이스토어 심사, 등록비, 업데이트 지연을 배제.
  * 모바일 브라우저에서 '홈 화면에 추가'를 통해 네이티브 앱과 동일한 전체화면 경험 제공 (안드로이드/iOS 동시 지원).
* **데이터베이스 및 파일 스토리지 (개인 Google 드라이브 & 스프레드시트):**
  * 데이터 주권(Data Sovereignty): 모든 사진 원본과 일정 데이터는 '사용자 본인의 구글 계정'에만 저장.
  * 개발자 중앙 서버에 개인정보/사진을 일절 보관하지 않아 해킹 위협 및 법적 보관 책임(Zero Liability) 원천 차단.

---

## 3. 백엔드 게이트웨이 및 CRUD 엔진 (Google Apps Script)
* **단일 라우팅 창구 (`doPost` 패턴):**
  * 사용자의 구글 시트에 연결된 구글 앱스 스크립트(GAS)를 웹 앱(Web App)으로 배포.
  * 단 하나의 엔드포인트 URL로 모든 원격 쓰기/수정/삭제 요청을 받아 `action` 이름표 기반으로 내부 전담 함수 분기 처리.
* **지원 작업 명세 (Full CRUD):**
  * **Create:** 일정 추가 (`appendRow`)
  * **Read:** 수십 년 치 일정/사진 데이터 일괄 조회 및 캐싱
  * **Update:** 특정 셀(오타, 제목, 자막 등) 좌표 지정 단일 수정 (`sheet.getRange(r, c).setValue()`)
  * **Delete:** 행 번호 변동 버그를 방지하기 위해 '고유 ID(rowId)' 기반 행 삭제 (`sheet.deleteRow()`)
* **경량 보안 (PassKey):**
  * GAS 웹 앱 URL 무단 호출을 막기 위해 요청 페이로드에 '모임 전용 비밀 암호(Token)'를 검증하는 로직 적용.

## 4. AI 연동 및 포토 스토리 파이프라인
* **사전 생성(Pre-generation) 원칙:**
  * 화면 재생 시 실시간 AI 호출을 금지(비용 및 지연 방지). 구글 시트 작성 단계에서 1회성 사전 생성.
* **시트 컬럼 이원화:**
  * `Story_Board` 열: 사용자가 입력한 짧은 메모/키워드 원본 보존 (예: "비바람, 7코스 정상, 꿀맛 커피").
  * `AI_Story` 열: 무료 Gemini API를 통해 생성된 감성적 2~3줄 자막 보관.
* **화면 연출:**
  * `AI_Story` 우선 표시, 부재 시 `Story_Board` 원본 표시 (Fallback).
  * 사진 서서히 줌인(Ken Burns 효과) 및 하단 영화 자막 페이드인 연출.

---

## 5. 단계별 개발 추진 계획
1. **1단계 (기본 뷰어 & CRUD):** GitHub Pages 정적 캘린더 UI 제작 + 구글 시트 데이터 연동 + GAS doPost 단일 라우터 CRUD 구현.
2. **2단계 (타임머신 & 포토 스토리):** 'N년 전 오늘' 초고속 필터링 + 사진 슬라이드쇼 및 시트 자막 페이드인 연출.
3. **3단계 (AI & 댓글 파이프라인):** 구글 시트 내 Gemini API 자동 호출 스크립트 추가 + 사진별 방명록(댓글) 기능.
4. **4단계 (온보딩 자동화 & PWA):** 원클릭 시트 사본 복제 템플릿 제작 + PWA manifest/서비스워커 적용.
